От установки до первого звонка

  1. Установите сервер. На Debian или Ubuntu выполните команду ниже. Дождитесь завершения установки.
  2. Откройте панель. Скрипт покажет адрес сервера и данные для входа оператора. Используйте их, чтобы войти.
  3. Пригласите собеседника. Создайте для него комнату в панели и отправьте персональную ссылку.
  4. Начните разговор. Собеседник открывает ссылку в браузере, а вы входите в его комнату из панели. Перед звонком проверьте камеру и микрофон.

Установка

Установочный скрипт (Debian / Ubuntu)

На сервере со свежей установкой Debian или Ubuntu выполните команду ниже. Скрипт создаст служебную учётную запись, настроит TLS-сертификат, службу systemd и учётную запись оператора. Если включён ufw, он откроет в нём нужные порты, иначе покажет, какие порты открыть.

curl -fsSL https://raw.githubusercontent.com/leyvanah/sozvon/main/contrib/install.sh | sudo sh

Когда установка завершится, скрипт покажет адрес сервера и пароль оператора. Для обновления запустите скрипт ещё раз. Если новая версия не запустится, он восстановит предыдущую.

По умолчанию создаётся операторская комната — панель для управления отдельными комнатами и персональными ссылками. Если вам нужна обычная комната с ожиданием перед входом, используйте параметр --operator-room no.

Список параметров установщика доступен по команде sh install.sh --help, если скрипт сохранён в файл install.sh. Можно указать домен, имена комнаты и оператора, порты и зеркало для скачивания, а также удалить сервер.

Ручная установка

Сервер SOZVON — один исполняемый файл на Go. В архив также входят веб-клиент и вспомогательные файлы. Ниже пример для версии 0.3.1; серверные архивы: Linux, Windows, macOS. Другие версии и архитектуры доступны в релизах. Пример распаковки и запуска на Linux:

tar xzf sozvon_v0.3.1_linux_amd64.tar.gz
cd sozvon_v0.3.1_linux_amd64
./sozvon -http :8443

В архиве находятся сервер sozvon, утилита администрирования galenectl, веб-клиент в static/, примеры настройки systemd и fail2ban в contrib/ и документация. Для проверки архива сохраните рядом файл SHA256SUMS из того же релиза и выполните sha256sum -c SHA256SUMS --ignore-missing.

Для сборки из исходников выполните:

git clone https://github.com/leyvanah/sozvon
cd sozvon
CGO_ENABLED=0 go build -ldflags='-s -w' -o sozvon .

На Windows: set CGO_ENABLED=0, затем go build -ldflags="-s -w". Кросс-компиляция — через GOOS и GOARCH: CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go build -ldflags='-s -w'.

TLS и домен

SOZVON может получать и обновлять TLS-сертификаты для вашего домена самостоятельно. Пример запуска:

./sozvon -http :443 -letsencrypt meet.example.com

Домен должен указывать на сервер, а порты 443 и 80 — быть доступны из интернета. Сертификаты сохраняются в data/acme/.

Если у вас уже есть сертификат, поместите cert.pem и key.pem в data/ и запускайте сервер без -letsencrypt. Если TLS обрабатывает обратный прокси, параметр -insecure позволяет запустить SOZVON за ним по HTTP. Пример службы systemd находится в contrib/systemd/sozvon.service.

Установщик поддерживает три режима. Выберите нужный с помощью параметра --tls:

Режим Что делает Когда подходит
letsencrypt-sslip (по умолчанию) Формирует доменное имя на основе IP-адреса через sslip.io и получает сертификат Let’s Encrypt Если своего домена нет, а нужен доступ через браузер
letsencrypt-domain Использует доменное имя, которое указывает на ваш сервер: --domain meet.example.com Если у вас есть домен, настроенный на сервер
self-signed Создаёт самоподписанный сертификат и показывает его отпечаток Если DNS или центр сертификации недоступны. Для подключения используйте приложение: браузер не доверяет такому сертификату

Комнаты и ссылки

Обычная комната доступна по адресу вида /group/name/. Вход можно защитить паролем. Если включена комната ожидания (лобби), гость вводит имя и ждёт, пока оператор впустит его в звонок. Пригласительная ссылка с токеном позволяет пройти без ожидания.

Операторская комната — панель, в которой вы создаёте отдельную комнату для каждого собеседника. Отправьте ему персональную ссылку; при необходимости доступ по ней можно отозвать. В панели видно состояние комнат и заявки на вход. Персональные ссылки операторской комнаты и приглашения для обычных комнат — разные способы доступа.

Настройки комнат хранятся в каталоге groups/, конфигурация сервера — в data/, файлы веб-клиента — в static/. Записи звонков по умолчанию сохраняются отдельно, в recordings/.

Для настройки комнат также можно использовать утилиту galenectl или редактировать JSON-файлы в groups/. В конфигурации комнаты называются группами. Большинство настроек описано в документации Galène: galene.md.

Клиенты

Браузер. Откройте ссылку на комнату — устанавливать приложение не нужно. Перед входом можно проверить камеру и микрофон и выбрать устройства.

Android. Приложение сохраняет список серверов и не даёт экрану гаснуть во время звонка. Оно использует тот же веб-интерфейс и запрашивает доступ к камере и микрофону. Скачайте APK в разделе приложений. Если сервер SOZVON уже развёрнут, APK можно скачать и с него: добавьте /sozvon.apk к адресу сервера, например https://meet.example.com/sozvon.apk. Версии подписываются одним ключом, поэтому приложение можно обновить поверх установленного. Следить за обновлениями помогает Obtainium.

Компьютер. Приложение на Electron использует тот же веб-интерфейс и включает мастер установки сервера. Установщики будут доступны в релизах. При желании приложение можно собрать самостоятельно; инструкции находятся в разделе desktop репозитория. Для звонка также можно пользоваться браузером.

Чтобы развернуть сервер из приложения, укажите адрес VPS и пароль root для подключения по SSH, затем выберите режим TLS. На сервере должна быть свежая установка Debian или Ubuntu. Мастер запускает тот же установочный скрипт contrib/install.sh, что и при установке через терминал.

Сквозное шифрование

Сквозное шифрование (E2E) включается в настройках комнаты. Аудио и видео шифруются в браузерах двух участников, а сервер пересылает зашифрованные данные. Для согласования ключей используется эфемерный ECDH, для шифрования кадров — AES-256-GCM. Перед разговором сверьте вслух пять эмодзи на экране: так вы проверите подлинность ключей.

Параметр require-e2ee делает сквозное шифрование обязательным: если его нельзя установить, соединение блокируется.

Режим поддерживает только двух участников. Реализация не проходила независимого аудита. Ограничения описаны в SECURITY.md.

Администрирование

Утилита galenectl позволяет создавать комнаты и пользователей, назначать пароли и права доступа. Пример команд:

galenectl create-group -group city-watch
galenectl create-user -group city-watch -user vimes -permissions op
galenectl set-password -group city-watch -user vimes
galenectl list-groups
galenectl list-users -l -group city-watch

Параметр -insecure у galenectl отключает проверку TLS-сертификата сервера; он не нужен при действительном доверенном сертификате. Административный API описан в galene-api.md, протокол клиента — в galene-protocol.md.

Для защиты от подбора пароля после неудачных попыток входа сервер увеличивает задержку перед следующей попыткой, а затем временно блокирует IP-адрес. Эта защита действует совместно для WebSocket, /recordings/ и API администрирования. В комплект входят фильтр и конфигурация jail для fail2ban, чтобы блокировать адреса на уровне файрвола. Для проверки доступности сервера используйте /healthz: работающий сервер отвечает 200 ok.

Сеть и TURN

SOZVON можно разместить на сервере с прямым доступом из интернета. В файрволе нужны TCP-порт веб-сервера (по умолчанию 8443, меняется параметром -http) и TCP- и UDP-порты TURN (по умолчанию 1194). Для передачи медиа разрешите входящий и исходящий UDP в верхнем диапазоне портов или задайте нужный диапазон параметром -udp-range.

Встроенный TURN-сервер настраивается параметром -turn. Значение :1194 включает его на всех сетевых адресах, auto используется по умолчанию, а пустая строка отключает встроенный сервер. Внешние TURN-серверы указываются в data/ice-servers.json. Для TURN через TLS используется параметр -turn-tls и порт 5349.

Если NAT или файрвол мешают соединению, разместите внешний TURN-сервер там, где он доступен обоим участникам, и укажите его в data/ice-servers.json. При использовании обратного прокси задайте proxyURL в data/config.json и настройте передачу WebSocket-соединений по пути /ws. Подробности — в galene-install.md.

Частые вопросы

Что это и кто автор?

SOZVON — форк лёгкого WebRTC SFU Galène Юлиуша Хробоцека. Маршрутизация медиа, кодеки и RTP основаны на Galène. Изменения SOZVON относятся к веб-клиенту и отдельным серверным возможностям. Проект распространяется по лицензии MIT.

GitHub заблокирован — что делать?

Для скачивания сервера установщик поддерживает зеркало: укажите его адрес параметром --mirror. Android-приложение можно скачать прямо с уже работающего сервера по адресу /sozvon.apk и установить из файла.

Нужны ли аккаунты?

Гостям не нужно регистрироваться. Для входа достаточно указать имя и получить доступ к комнате — по приглашению или с разрешения оператора. В SOZVON нет телеметрии.

Как обновляться?

Повторно запустите установочный скрипт. Он загрузит новую версию и вернёт предыдущую, если обновлённый сервер не запустится. Android-приложение подписывается одним ключом и обновляется поверх установленной версии.

Куда сообщать об уязвимостях?

Об уязвимостях сообщайте приватно по инструкции в SECURITY.md, не публикуя подробности в открытом issue. Для обычных ошибок и предложений используйте GitHub. В CONTRIBUTING.md описано, как подготовить сообщение об ошибке или предложить исправление.
