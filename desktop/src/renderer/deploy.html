Развернуть свой сервер

SOZVON будет установлен на ваш VPS по SSH. Нужен чистый сервер с Debian или Ubuntu и доступ с правами root.

Пароль используется только на время установки и никуда не сохраняется.
A-запись домена уже должна указывать на этот сервер.

Проверьте отпечаток сервера

Отпечаток ключа
Было раньше

Сверьте его с тем, что показывает панель управления вашего хостинга. Если отпечаток не совпадает, кто-то может выдавать себя за ваш сервер — а вы собираетесь дать ему пароль root.
