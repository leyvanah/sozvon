Видеозвонки
на своём сервере.

Для разговоров один на один. Вы устанавливаете SOZVON на своём сервере, а собеседник подключается по ссылке в браузере — без регистрации.

УстановкаДокументация

Кто может подключиться

Пригласите собеседника по персональной ссылке или впустите его из комнаты ожидания.

О комнатах и ссылках

Персональные ссылки

Создайте отдельную комнату для собеседника и отправьте ему персональную ссылку. При необходимости доступ можно закрыть.

Комната ожидания

Если включена комната ожидания, вы решаете, кого впустить в звонок. По пригласительной ссылке можно войти без ожидания.

Защита от подбора пароля

Чтобы затруднить подбор пароля, сервер ограничивает частоту попыток входа. После повторных ошибок он увеличивает задержку, а затем временно блокирует IP-адрес. В комплекте есть фильтр для fail2ban.

Шифрование при звонках один на один

Сквозное шифрование включается в настройках комнаты. Установщик включает его по умолчанию.

Как работает шифрование

Аудио, видео и текстовый чат шифруются в браузерах участников, а сервер пересылает зашифрованные данные.

Перед разговором сверьте вслух пять эмодзи, которые видите на экране. Так вы проверите подлинность ключей.

Режим E2E поддерживает только двух участников. Реализация не проходила независимого аудита.

Установка

Сервер SOZVON написан на Go и поставляется одним исполняемым файлом. На сервере со свежей установкой Debian или Ubuntu скрипт настроит защищённое соединение, запуск службы и учётную запись оператора и откроет нужные порты в ufw, если он включён.

curl -fsSL https://raw.githubusercontent.com/leyvanah/sozvon/main/contrib/install.sh | sudo sh

Когда установка завершится, скрипт покажет адрес сервера и пароль оператора. Войдите в панель, создайте комнату и отправьте собеседнику ссылку.

Все релизы

Для звонков можно пользоваться браузером или приложением. В приложении есть мастер установки SOZVON на VPS: укажите адрес сервера и данные для входа по SSH: root или пользователь с sudo, пароль или закрытый ключ.

Приложения

WindowsEXE↓ AndroidAPK↓ macOSApple Silicon↓ macOSIntel↓ LinuxDEB↓ LinuxAppImage↓

Установщики пока не подписаны, и при первом запуске система предупредит об этом. Windows: в окне SmartScreen нажмите «Подробнее», затем «Выполнить в любом случае». macOS: перетащите Sozvon в «Программы»; если система откажется открыть приложение, зайдите в «Системные настройки» → «Конфиденциальность и безопасность» и нажмите «Всё равно открыть». Linux: DEB — для Debian, Ubuntu и Mint (sudo apt install ./sozvon-linux-amd64.deb), AppImage — для остальных дистрибутивов; на Ubuntu 23.10 и новее AppImage не запустится, там нужен DEB. Файл можно заранее сверить с SHA256SUMS.

Если сервер SOZVON уже развёрнут, APK для Android можно скачать прямо с него. Добавьте /sozvon.apk к адресу сервера — например, https://meet.example.com/sozvon.apk. При установке Android попросит разрешить установку из этого источника.
